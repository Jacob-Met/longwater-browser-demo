## Delivered behavior

A player can preview a watch file while retaining the current watch and its report. Explicit replacement rebuilds the complete native journal and the readable report for the adopted partial or completed watch. The same behavior works in the modular page and its actual standalone offline artifact. The report remains a readable snapshot; the watch JSON remains the resumable file.

A concrete composition defect was found before qualification. After successful file adoption, an authored one-shot native replay/display refusal left the earlier journal and its report accessible. The page could truthfully say that day 5 had opened while **Download watch report** still downloaded the old day-2 HTML. The correction adds one line in the file owner's existing game callback: hide the journal after adoption/display failure. The adopted watch's JSON download and save recovery remain available. The existing journal `start`/restore path reopens the journal after a successful replay, including a deliberate same-page re-open.

The report owner’s module, stylesheet, journal implementation, six native cases and all documentary leaves are unchanged. The simulation, save schema, file validation/admission, trends and reset implementations remain exact. No new dependency, account, service, CI or deployment mechanism is introduced.
