# Derivative and private-custody boundary
These three public documents are constructed from verified, immutable raw receipts using an explicit field whitelist. They are not byte-exact copies of the original reports.
Native filesystem roots, account/host/device identifiers, private estate references and operational URLs are omitted. No raw or nested archive, source-bearing browser profile, transport log or native execution script is embedded.
Test counts, source identities, oracle identities, failure classification, qualification boundaries and cryptographic digests are retained. Raw original failures and successor results remain unchanged in private custody. Private packet digests below allow byte identity to be checked by an authorized reviewer without disclosing locations.
