## Repaired receiving boundaries

The first candidate passed its normal-path checks but an independent source-transition probe exposed a custody gap: an inert comment changed SavedWatch after native validation and before ordinary packaging, yet publication succeeded. This demonstrated different validation and packaged bytes, without asserting changed simulation behavior.

The command now captures SavedWatch, simulation glue and WASM bytes, executes those captured modules directly, then decodes the actual packaged bindings and requires exact byte equality. Recognized binding and transformation counts must be exactly one. This rejects unsupported layouts, cached file-URL substitutions and source changes restored before a pathname reread. Receipt validation hashes describe the executed-and-packaged bytes. No original packager, SavedWatch, glue or WASM source was changed.

A separate injected browser failure showed that a silently refusing FileList setter could leave no selected File while the first controller reported delivery. The controller now reads back the FileList and requires exactly the intended File before dispatching a change. A refusal preserves any pending manual preview and its explicit confirmation route.
